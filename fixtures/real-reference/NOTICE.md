# Notice: licensed reference data

The samples in this folder are converted from licensed security master and corporate actions exports. The data is not public.

- Receiving the kit does not give you a license to this data. Check the license under which the data was obtained before you redistribute these files or anything converted from them.
- The samples are small: 28 to 864 rows of each source file. The source rows are in `source/`, bytes unchanged, and `source/SHA256SUMS` lists their SHA-256. `rebuild.sh` rebuilds the samples from `source/`.
- The samples are for learning the format. Do not use them for trading, pricing or any other decision.

The Reference data samples document describes each sample and the conversion rules.
